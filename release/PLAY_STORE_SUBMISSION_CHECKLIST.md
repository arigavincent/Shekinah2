# Play Store Submission Checklist

## Store assets

- App icon
- Feature graphic
- Screenshots:
  - Home
  - Sermons
  - Live
  - Bible
  - Giving
- Short description
- Full description
- Privacy policy URL
- Support email

## Policy declarations

- Account creation and deletion path
- User-generated content moderation statement
- Payment handling explanation
- Notification usage
- Data collection disclosure

## Functional checks before upload

- Signed build installs cleanly
- Upgrade over previous build works
- App opens without developer tooling
- Offline Bible works after airplane mode
- Downloaded sermons reopen after restart
- Card checkout opens correctly
- M-Pesa request starts correctly
- QR check-in screen loads
- No debug banners or placeholder secrets

## Release notes

Recommended first release notes:

- live streaming
- sermon video and audio library
- offline Bible
- prayer wall
- giving
- reading plans
- member QR check-in
- community chat and testimonies
